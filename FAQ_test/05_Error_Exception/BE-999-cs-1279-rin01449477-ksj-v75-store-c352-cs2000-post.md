BE-999: KSJ V75 Store C352 - CS2000 - Posting : Posting MQ_A terminated with file stuck

## 症狀

V75 門市 C352 執行 Posting 時，MQ_A 程序被終止（terminated），錯誤訊息為「String or binary data would be truncated」，導致 posting 檔案卡住無法完成上傳。

## 根因

用戶在 POS 的 CashVarComment 或 DayEndComment 備註欄位輸入了包含換行符號（line break）的內容。PCD 94 code 的備註欄位必須為單行文字，換行符號導致資料寫入資料庫時超出欄位長度限制，觸發 SQL truncation error。

## 解法

在產生 PCD 檔案時，對 94 code 的 CashVarComment 及 DayEndComment 欄位內容進行處理，將換行符號（line break characters）替換為空白字元（whitespace），確保備註內容為單行格式。修正版本：V750.04R09C、V750.04R10、v750.05。
