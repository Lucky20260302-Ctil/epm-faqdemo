## 🔍 搜尋使用指南

### 基本搜尋 — 直接打字即可

喺搜尋欄輸入關鍵字，系統會**同時搜尋以下所有範圍**，唔需要指定欄位：

| 搜尋範圍 | 說明 | 例如搜 `printer` 會命中… |
|---------|------|--------------------------|
| **Tag** | 筆記標籤 | `tags: [faq, printing]` |
| **檔名** | 筆記檔案名稱 | `BE-698-printer-error.md` |
| **內文** | 問題描述、根因、解法 | 「Printer 無法連線…」 |
| **分類名稱** | 七大業務分類 | `06_Printing_Hardware` |
| **Jira Summary** | 原始 Jira 摘要 | 「Printer OPOS error」 |
| **Frontmatter** | 結構化欄位 | `project: BE`, `issue_key: BE-698` |

### 進階搜尋 — 精準篩選

想收窄範圍，可以用以下前綴：

| 語法 | 用途 | 例子 |
|------|------|------|
| `tag:#be` | 只搜 Backend 專案 | 搵所有 BE 嘅 FAQ |
| `tag:#fe` | 只搜 Frontend 專案 | 搵所有 FE 嘅 FAQ |
| `tag:#mp` | 只搜 MPOS 專案 | 搵所有 MP 嘅 FAQ |
| `path:05_Error_Exception` | 只搜「錯誤與異常」分類 | 搵所有 Error 相關 FAQ |
| `path:06_Printing_Hardware` | 只搜「列印與硬體」分類 | 搵所有列印相關 FAQ |

### 組合搜尋

可以多個條件一齊用：

```
tag:#fe path:06_Printing_Hardware printer
```
→ Frontend 專案 + 列印分類 + 關鍵字 "printer"

### 搜尋貼士

- ✅ **打關鍵字就得**，唔使記語法 — 例如 `timeout`、`coupon`、`member search`
- ✅ **中英文都支援** — 可以打 `列印` 或 `printer`
- ✅ **Jira Key 都可以搜** — 直接打 `BE-1003` 或 `FE-1440`
