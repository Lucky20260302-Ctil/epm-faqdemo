## FAQ 收錄標準

- ✅ 有明確根因分析 + 解決方案

- ✅ API 整合錯誤、已知錯誤碼與排查步驟
- ❌ Typo、文案修改、一次性數據修復
- ❌ 純 UI 微調、舊版本 Bug（已有 Fix Version 且不再出現）
