# EP23CITYU-528: Browser Autofill Overwrites Contract Sum Field with User ID

## 問題

Browser auto-fills Total Contract Sum field with User ID instead of contract sum

## 根因

Browser autofill/saved form data interfering with input field

## 解法

Set autocomplete=off on field; clear browser cache
