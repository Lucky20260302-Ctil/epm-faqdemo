# FE-1646: [CS-1377][INC2847125][INC2845617][INC2847125]miss running cs2Kconnect schedule while doing dayend

## 問題描述

【[CS-1377](https://jira.tapestry.support/browse/CS-1377)】PRC region，升级到V75以后，连续出现每天有10+店铺有dayend issue，检查发现都是丢失了dayend info.

经过跟V72的cs2Kconnect的log对比，POS V72 在做dayend的时候，会强制运行一次cs2kconnect，

> 📎 **OC244till0_V72.png** — [查看附件](https://ctil.atlassian.net/rest/api/3/attachment/content/fa21cb64-1d55-47c5-893c-9bf21f4abfb2)（需 Jira 登入）
而升级到POS V75以后，这个强制执行的任务丢失了，而店铺不知道这个变更，没有等待10+分钟，从而导致大批量出现dayend issue（当天没有上传dayend info，第二天开机以后，cs2kconnect自动运行，会自动将dayend info上传，dayend issue 自动fix）。
