# FR-RPT-408: FR-RPT-408: Price comparison of received quotations (for Single Envelope Approach)

## 需求描述

Requirement ID:	FR-RPT-408	Requirement Type:	Report Requirements
Parent Requirement #:
None
Description:
D.	Generation of Reports / Documents
3.55.	Summaries and documents to be generated for the features and functions related to different procurement procedures shall include but not limited to the following:
(h) Price comparison of received quotations (for Single Envelope Approach)
Rationale:
None
Acceptance / Fit Criteria:
The Platform support feature to export the Price Comparison / Assessment Summary in Excel, as outlined in FR-RTR-203.
This report provides information on whether bidders / tenderers have submitted responses to the RFQ / Tender.
If responses are received, the report organizes them in a table format for comparison of:
The total bid / tender sum.
The package sum for each requisition item group, along with the following details:
Unit prices in the selected currency
Amounts in HKD
The information provided in their submissions for Supplier Remarks #1 to #3 (e.g., Minimum Quantity, Discounts in HKD or Discount %, Lead Time).
