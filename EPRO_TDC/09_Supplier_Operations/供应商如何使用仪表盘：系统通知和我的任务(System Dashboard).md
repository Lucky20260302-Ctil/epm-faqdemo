4 System Dashboard
   4.1 System Notification (Home Page)


All email notifications received from EPRO will be stored on the system.





Notification can be filtered using search criteria.






4.2 My Task


All system operations are initiated and managed through individual e-Forms under “My Task”
section.


   4.2.1   My Task – New Requests: Initiating New e-Forms


Available e-Form can be initiated under “New Requests”, suppliers can create new e-Forms in
various stages, including:

 Module          Related e-Form
 RFQ / Tender        •   Offer Response
                     •  No Offer Response
                    •  Query
 Supplier             •  Update Master / Sub-Account
 Management         •  Change Supplier Information
                     •  Update Business Registration (BR) Information






Each e-Form provides brief information , e.g. e-Form type, request number, and last update
time.





e-Forms are proceeded by four (4) stages as follows:

   •  Stage 1 Draft: All fields are editable and updatable.





   •  Stage 2 Review and Validate: e-Form is “read only” under this stage and system
       validates the e-Form to see if any missing or incorrect data.






•  Stage 3 Confirm: Read and confirm the terms and conditions, e-Form can only submit
        after all checkboxes are checked.





   •  Stage 4 Submission: Acknowledgement record of e-Form submission .






4.2.2   My Task – Drafts


All incomplete e-Forms including those with no entered fields but only e-Form created are
saved under “Drafts”. Users can filter relevant e-Forms using search criteria.





Action buttons for e-Forms are available at the end of each page.

The system monitors user activity and auto-saves every 30 seconds, displaying the latest
record date and time.





Abandon Changes: User is able to abandon changes that have not been manually saved or auto
saved, and revert the form to the last saved state.

Discard e-Form: Delete the draft entirely from “Drafts”.

Save & Edit Later: Close the form for future editing and save the updates manually.


Review & Validate: User submits the e-Form manually to perform system validation (refer to
section 4.2.1 for details).






4.2.3   My Task – Completed Task: Viewing Submitted e-Forms


Supplier can search and view all submitted e-Forms under the “Completed Task” section.





The e-Form related history can be tracked with completed e-Form details, and exported as a
PDF file.
