1. System Requirements

       Website: https://epro.hktdc.org

The recommended internet browsers and supported operating systems for Internal Users are
as follows:
 Recommended Internet Browser   Supported Operating Systems
 Microsoft Edge                 Windows 10/11, macOS Catalina (10.15) and later
 Google Chrome                Windows 10/11, macOS Catalina (10.15) and later
*EPRO users need to ensure their browsers have the same / higher version than the number stated above.

     The Platform is primarily designed to support Internal Users using workstation PCs
       within the office network.

     The minimum screen resolution required is 1024 x 768 pixels, with a suggested
       resolution of 1680 x 1050 pixels.

      Full functions on mobile and tablet devices are not supported for Internal Users. Mobile
      and tablet devices are limited to manage for review and approval function, e.g.
      document download, view, and action to approval request.
