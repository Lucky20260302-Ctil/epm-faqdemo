6.1.2  RFQ / Tender Setting


Draft of Tender Setting are auto-generated in selected buyer account upon approval of
Procurement Initiation.

Step 1: Buyer select the relevant e-Form under “Drafts” section.





Step 2: Update the information of Tender / RFQ.





Step 3: Define if NDA / Confidentiality Undertaking is required for the current exercise, attach
template file and set up acknowledgment receipt if required.






Step 4: Define if Briefing / Site Visit is required for the current exercise and set up
acknowledgment receipt if required.

Buyer needs to submit e-Form for Briefing / Site Visit Attendance Confirmation if it is
mandatory.

Fill in the minimum of attendee(s) that the supplier needs to provide for registration e-Form,
or;

Attach registration form for supplier to fill in and submit.







Step 5 & 6: Define if the query and addendum function is enabled for the current exercise and
set up acknowledgment receipt if required.

Set up the minimum time for query submission and release addendum.





Step 7: Define if the extension function is enabled for the current exercise and set up the
extension details.






Step 8: Set up the E-Tender box for supplier submission. Buyer can add any required
document(s) by   button.





Step 9: Select the approval route from drop down menu, specify the approval details (Refer to
section 4.2.2.2 for approval settings).

Step 10: Click “Review & Validate” to proceed.





Step 11: Click “Confirm & Submit” after review.

Step 12: Review and confirm the terms and conditions and click “Yes, proceed with submitting
the e-Form”.

An email for approval request is sent to the selected approver after submission.
