## 驗收標準

The Platform supports the following user roles to export the details in Excel:
Finance users
The Platform exports the following details in Excel:
Summary: This worksheet lists the number of calendar days for the total turnaround time from RFQ/Tender Creation Date to . It also includes the required calendar days between each checkpoint for RFQ/Tender exercises using the Two Envelope Approach. The summary is categorized by procurement category and by month over a period of three years.
Raw Data: This worksheet provides the raw data used to create the Summary worksheet.
Note: The detailed design will be provided in a later SA&D stage.
The required calendar days between each checkpoint for RFQ/Tender exercises are as follows:
RFQ/Tender Creation Date
RFQ/Tender Invitation Approval Submission Date
RFQ/Tender Invitation Approval Completion Date
RFQ/Tender Issuance Date
RFQ/Tender Return Final Closing Date
RFQ/Tender Creation to RFQ/Tender Final Closing (Calendar Day)
Technical Envelope Opening Date
Technical Assessment Start Date
Technical Assessment Sign-Off Date
Commercial Envelope Opening Date
Commercial Assessment Start Date
Overall Result Sign Off Date
Technical Envelope Opening to Overall Result Sign Off (Calendar Day)
1st PTN Issuance Date
Last PTN Return Date
1st PTN Issuance to Last PTN Return (Calendar Day)
Total RFQ/Tender SLA (Tender Creation to Last PTN Return) (Calendar Day)
