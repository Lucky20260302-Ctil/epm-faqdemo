## 需求描述

D.	Generation of Reports / Documents
- **3.55** Summaries and documents to be generated for the features and functions related to different procurement procedures shall include but not limited to the following: (k) Technical Assessment Scoring Sheet of individual members and summary of technical assessment (for Two Envelope Approach)
## 驗收標準

The Platform support feature to export the Technical Assessment Summary in PDF, as outlined in FR-RTR-208.
This report provides detailed information of the technical evaluations, including weighting and passing marks for both the Semi-Final and Final Rounds.
The report organizes the information in a table format for comparison of:
The pass/fail results or raw and weighted scores for each bidder/tenderer from the Semi-Final Round, along with the list of reasons/remarks from each technical assessor for each bidder/tenderer.
The raw and weighted scores for each bidder/tenderer from the Final Round, along with the list of reasons/remarks from each technical assessor for each bidder/tenderer.
Whether the bidder/tenderer has been shortlisted for the Commercial Evaluation.
