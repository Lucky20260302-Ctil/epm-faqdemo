## 需求描述

    - **3.1.29** The Platform shall support brand customisation or configuration features to its user interface. At a minimum, the HKTDC logo shall be appropriately placed within the Platform.
## 驗收標準

Login Page for Internal Users:
The logo can be positioned on the top right of login page and top left of each web page.
The image and text displayed on the login page can be updated by System admin users.
Login Page for External Suppliers:
The logo can be positioned on the top right of login page and top left of each web page.
The image and text displayed on the login page can be updated by System admin users.
Wireframe of the Platform:
Action Button Colour: The default font color for action buttons will be white with a navy-blue background, which can be updated by System admin users.
Function / Zone Title: The default font color and background can be updated by System admin users.
The Platform shall successfully perform all the actions outlined in the Use Case 26.
