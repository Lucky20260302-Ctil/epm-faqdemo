## 需求描述

    - **3.1.4** The user interface shall be concise with user friendly navigation.
    - **3.1.5** The Contractor shall design and develop the Platform to allow HKTDC staff and external suppliers to navigate in a user-friendly way. The Platform should facilitate seamless processes for all purchase management, proposal submission, and supplier management, allowing easy access and efficient execution of these activities.
## 驗收標準

Include clearly labeled menus and navigation options for easy access to different functionalities.
Provide consistent layout and design elements for a seamless user experience.
Action Button Colour: The default font colour for action button will be in white with navy-blue background.
Date Picker: Date picker allows user to select a date from the calendar or directly enter Date e.g. “YYYY/MM/DD” or “YYYYMMDD”, the Platform will smartly check the format and add the forward-slash (/) automatically.
Date & Time Picker: Date & Time Picker allow the user to select a date & time from the calendar or directly enter the date and time “YYYY/MM/DD 24HH:mm” or “YYYYMMDDHHmm”, the Platform will check the format and add the forward-slash (/), Space and Colon (:) automatically.
Text Field: The Platform provides the following features for text field.
Single Line Text Field: Text field allow user to input a single line of text.
Multi-Lines Text Field: Text field allow user to input a multi-line text with auto scroll bar.
To support user to have full view on the text field content, some text field will have this icon next to the field name. By clicking this icon, it will display the entire content of text area.
Dropdown List: The dropdown list will be used for showing a list of values for user to select. By default, the list of values will be sorted in alphabetical order.
However, some dropdown lists will be sorted in other appropriate orders, e.g. the status of To Do according to the workflow steps.
Dropdown List with Filter Box: The dropdown list also provides the filter box. When the user input some word in the filter box, The Platform will automatically filter the match option in real time.
Radio Button: Radio button allows user to select only one option from the available options.
Checkbox Button: Checkbox button allow the user to check or uncheck one or multiple options.
Offer intuitive navigation paths to help users locate information and perform tasks efficiently.
Wireframe of the Platform:
Login Page
The Platform mainly uses white as background.
The Platform uses font type Arial (Sans-Serif) for English and Microsoft JhengHei (Sans-Serif) for Chinese, also the default font size for English and Chinese is 13 points.
