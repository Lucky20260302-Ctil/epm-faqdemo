## 需求描述

3.1.18	There shall be a “document pool” that contains all the templates of procurement documents, allowing Internal Users to utilise or download the appropriate templates for each stage and type of procurement exercise.

## 驗收標準

For System admin users, the document pool functions may include:
Access to a centralized repository of procurement document templates.
Search and filter options for specific template retrieval by category.
Download function for template retrieval.
Capability to upload new templates categorized by procurement exercise stage and type, or update existing templates with version control.
Ability to specify effective date and indicate template status as active or inactive to restrict user access for listing, viewing, and downloading.
Audit trail feature to monitor template modifications.
< Screen mock-ups will be provided in the later SA&D stage >
For all users to view and download templates, the document pool functions may include:
Access to a centralized repository of procurement document templates, with clearly labeled menus for user-friendly access.
Search and filter options for specific template retrieval by category.
Download function for template retrieval.
Version control to ensure access to the most recent template versions.
< Screen mock-ups will be provided in the later SA&D stage >
The Platform shall successfully perform all the actions outlined in the Use Case 16.
