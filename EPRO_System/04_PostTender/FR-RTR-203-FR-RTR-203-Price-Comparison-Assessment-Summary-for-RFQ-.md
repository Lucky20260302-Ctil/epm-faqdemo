## 需求描述

3.6.	Submission of Quotations / Tenders
3.6.7	Quotation / Tender Opening
(g) The Platform shall generate price comparison / assessment summary for RFQ / tender in prescribed layout (with indication of no submission or technically disqualified, if applicable).

## 驗收標準

The following reports are available for internal users with access control:
Price Comparison / Assessment Summary: This report provides information on whether bidders / tenderers have submitted responses to the RFQ / Tender. If responses are received, the report organizes them in a table format for comparison of the total bid sum/total tender sum. And, it may include the package sum for each requisition item group, along with details such as unit prices in the selected currency, amounts in HKD, and the information provided in their submissions for Supplier Remarks #1 to #3 (e.g., Minimum Quantity, Discounts in HKD or Discount %, Lead Time).
