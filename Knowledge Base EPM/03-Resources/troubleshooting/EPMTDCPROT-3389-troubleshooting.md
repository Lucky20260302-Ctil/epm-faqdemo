# EPMTDCPROT-3389: EPRO-932[Production] No show of validation error but block e-form submission

## 問題

Supplier reported that there is no validation error displayed after Review and Validate, but system block the submission without revising.
[Image]
Upon checking with previous testing experience, the validation error should be about selecting more than 3 procurement categories, which has been fixed.
The display of validation error is important for external suppliers to identify the appropriate fields to make necessary changes in order to pass the system validation. Without the validation error, suppliers will have no clue on the required amendments.
 
Please investigate the root cause for not showing any validation error.

## 根因
