# FE-1602: Front end POS replace F6 Open Item button by Retrieve Order function

## 問題描述

[Tapestry Jira Ticket # CS-1307] Replacing the <F6 Open Item> button with a <F6 Retrieve Order> function if the open item function is disabled. We plan to retain the Retrieve Order button in the F7 More panel. This approach is intended for users who are already familiar with the current operational flow and wish to minimize any disruption to their practices. Development for version 7.2 is expected to be completed by the end of this week. The delivery timeline will depend on the QA team's schedule. As for version 7.5 development, we can incorporate this change in the upcoming release. However, since the next release for v7.5 may include other modifications, additional testing time might be necessary.
