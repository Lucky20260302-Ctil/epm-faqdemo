# FR-GR-025: FR-GR-025: Export Formats for Reports/Documents

## 需求描述

Requirement ID:	FR-GR-025	Requirement Type:	General Requirements
Parent Requirement #:
None
Description:
3.1.28	All reports generated by the Platform shall be exported in Excel, Word and/or PDF format as appropriate for the report type.
Rationale:
None
Acceptance / Fit Criteria:
The Platform should allow exporting all system-generated reports and documents in PDF and Excel formats.
The following system-generated documents will be exportable in Word format:
Letter of Acceptance (Standard template)
Contract document (Standard template)
System-generated documents will support mail merge using reserved placeholders for:
Procurement Strategy related data:
Procurement Strategy details like reference number and subject.
RFQ/Tender related data:
RFQ/Tender details such as reference number and subject.
Selected/Awarded supplier details including name and address.
PO/contract details like total award sum, package total of grouped items, commencement date, and end date.
The Platform used a third-party .NET application API, GemBox.Document, which offers basic text formatting, table structures, and simple styling options for converting HTML to Word format. In comparison, the comprehensive features provided by the Microsoft Word software application include advanced formatting capabilities, intricate layout designs, detailed customization options for fonts, styles, and formatting, and support for complex document structures such as headers, footers, and references. To access the full range of Word format features, HKTDC can provide the Microsoft Word software application for integration with the Platform.
The Use Case will be documented in the RFQ and Tender section of the e-Procurement Requirements and Supplier Management Requirements.
