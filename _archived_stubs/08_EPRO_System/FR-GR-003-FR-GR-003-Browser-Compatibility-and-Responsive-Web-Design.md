# FR-GR-003: FR-GR-003: Browser Compatibility and Responsive Web Design

## 需求描述

Requirement ID:	FR-GR-003	Requirement Type:	General Requirements
Parent Requirement #:
None
Description:
3.1.2	The function and layout of the Platform shall not be dependent on any browser, including Microsoft Edge, Chrome, Firefox, Safari, etc. The Platform shall be designed to be fully responsive, adapting seamlessly to different devices and screen sizes.
Rationale:
None
Acceptance / Fit Criteria:
The Platform is primarily designed to support Internal Users and External Suppliers using workstation PCs within the office network.
The system's screen design incorporates the concept of "Responsive Web Design", allowing pages to adjust automatically to various screen resolutions. The minimum screen resolution required is 1024 x 768 pixels, with a suggested resolution of 1680 x 1050 pixels. If the zoom ratio of Edge is increased to 150%, the page will adapt to the screen only if the resolution is below 1680 x 1050 pixels.
Full functions on mobile and tablet devices are not supported for Internal Users and External Suppliers. External Suppliers using mobile and tablet devices are recommended to manage acknowledgment of receipt, document download, and viewing. Internal Users using mobile and tablet devices are recommended to download, view, and approval documents.
